# Neutral runtime setup for independent validation

Use a new directory created with `mktemp -d /tmp/oceanix-pdf-qa-XXXXXX`; set `OCEANIX_PDF_QA_DIR` to that exact returned path for each command. Do not modify .env or use the application database. The standalone harness selects testing/SQLite/files in this directory. Verify the manifest and isolated configuration before mutations. It is not a production route registration.

Initialize synthetic fixtures with `php tests/Support/Documents/QaFixture.php`, then start `php -S 127.0.0.1:<free-port> -t public tests/Support/Documents/QaRouter.php` with the same variable. Read generated manifest.json for IDs and routes. Log in using `/__pdf-qa/login/{id}`. Stop the server after validation; retain evidence paths. Each reviewer uses separate fixture/server/browser sessions.

Manifest fixtures include author (company/platform admin), authorB (other company), libraryUser (separate grants), learner and unrelated identity, company/platform document UUIDs, three editor paths, preview and learner routes. Use exact generated values, not invented IDs. Fixture includes >60 files and duplicate/long names; verify rendered outcomes independently. Real upload fixture is tests/Fixtures/lesson-guide.pdf.

Remediation fixture additions: `emptyAuthor` and `emptyEditor` identify a third synthetic company with no PDFs. `revoke-archive-permission` / `restore-archive-permission` change only the libraryUser's Archive grant while preserving View/Reuse. `archive-count <company-library-uuid>` is a read-only retained-record count. The last two company/platform library PDFs each have a saved source association in another lesson; these provide representative reuse sources. All additions use the same explicitly selected disposable directory.

With the same directory variable, fixture commands `revoke-library`/`restore-library` change only the synthetic library profile. `fail-list`, `fail-reuse`, `fail-archive`, `fail-storage` and corresponding `restore-*` commands enable/disable scoped test faults. Commands `revoke <assignment-id>`, `expire-preview` and `prepare-copy` provide assigned-learner and retained-copy fixture transitions. After prepare-copy, copy.json contains synthetic source/draft IDs; use observed UI/API behavior to establish outcomes.
