## Preserved contracts and scope decisions

The new catalog never aggregates platform and company documents. A tenant administrator's existing Gate bypass cannot bypass the explicit owner query/check. The platform path continues to use Account authority, as approved, and does not introduce grantable platform profiles.

Archival changes discovery/new reuse only. The original document metadata, private bytes and lesson associations are retained; contextual delivery continues to require its existing saved-link and attachment authorization. The lock wait is followed by a separate archival query, preserving the approved serialization boundary without changing the published-content contract.

The existing insertion implementation is reused rather than replaced. New transport recovery and child confirmation handling stay inside the approved PDF operation/regression surface. No new product workflow, permission grant backfill, public download contract, restore operation or physical deletion was introduced.
